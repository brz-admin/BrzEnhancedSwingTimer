# BReST
Brz enhanced SwingTimer.
<img width="1212" height="723" alt="image" src="https://github.com/user-attachments/assets/a89f37bb-ac4e-4fdb-8a90-1be09cdf81d9" />


A swing timer for World of Warcraft 1.12 (vanilla). It shows one bar for your main hand, off hand and ranged weapon, and has a settings window that controls how they look, move and hide.

## Install

Copy the `BrzEnhancedSwingTimer` folder to `Interface/AddOns/` and restart the game. The folder name must stay `BrzEnhancedSwingTimer`, because the textures and fonts are loaded from that path.

## Use

| Command | What it does |
| --- | --- |
| `/brest` | Opens or closes the settings window |
| `/brest unlock` / `lock` | Unlocks the bars so you can drag them, or locks them again |
| `/brest sim` | Turns the swing simulation on or off |
| `/brest reset` | Centers the bars |
| `/brest debug` | Prints every swing that is detected |

## Settings window

The window shows every enabled bar while it is open, and loops fake swings so you can see your changes live. Closing it locks the bars and stops the simulation.

- **General:**
  - Group the bars in one frame, or place each bar on its own.
  - Scale, opacity, position, and the group background, border and spacing.
  - Update interval.
- **Main Hand, Off Hand, Ranged:** each bar has four tabs.
  - **Bar:**
    - Size, texture and colors.
    - Border.
    - Animation: left to right, right to left, center to the sides, sides to the center. It can drain or fill.
    - Optional spark, with size and color.
    - Main hand only: a color change while Heroic Strike, Cleave, Maul or Raptor Strike is queued.
    - Copy the look to another bar.
  - **Icon:**
    - Equipped weapon or a custom icon, with a picker over your spellbook and equipment.
    - The queued swing spell's icon can replace it.
    - Position, size and offsets.
  - **Timer:** font, size, outline, shadow, color, position, format and decimals.
  - **Visibility:**
    - Hide out of combat and/or when no swing is running.
    - Delay before fading, fade in and out times, and a fade curve.
    - Apply the settings to all bars.
- **Profiles:** per character. Create (a copy of the current one), switch, reset and delete.
- **Footer:**
  - **Unlock bars:** drag the bars.
  - **Simulation:** loop fake swings.
  - **Test hiding:** make the preview follow the visibility rules, then use the Main hand / Off hand / Ranged buttons to send a swing.
  - **Queued spell:** preview the queued-spell icon and color.

## How swings are detected

Swings are read from the combat log, and the patterns are built from the client's `GlobalStrings`, so they work in any locale.

- **Melee:** the hand is picked from the two swing timers. When they are too close to tell apart, the damage of the hit is compared to your weapon damage.
- **Ranged:** Auto Shot, Shoot and Throw start the ranged timer.
- **Next-swing abilities:** Heroic Strike, Cleave, Maul, Raptor Strike and Slam restart the main hand timer.
- **Queued spells:** the addon looks for the action button holding one of these spells and checks whether it is pressed. The spell has to be on one of your action bars to be detected.

## Files

- `core.lua`: settings, profiles, events and the slash command.
- `barFrame.lua`: the bars, their animation, simulation and hiding.
- `configMenu.lua`: the settings window.
- `media.lua`: texture and font lists.
- `parser.lua`, `utils.lua`: combat log parsing and hand detection.
- `Libs/`: AceLibrary, AceLocale and Babble-Spell.
- `Textures/`: generated by `tools/make_media.py`, which needs Python with Pillow.
- `Fonts/`: Open Sans, licensed under the SIL Open Font License (`Fonts/OFL.txt`).

## Saved variables

`BReST_Config` (account wide, holds the active profile name) and `BReST_Profiles` (per character). Profiles from older versions are converted when they load.
